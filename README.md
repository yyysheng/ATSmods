## Project

[Source and documentation](mods/ATS_Reverse_Trajectory_Predictor) · [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3792042919) · [Latest release](https://github.com/yyysheng/ATSmods/releases/tag/reverse-trajectory-predictor-v0.11.3)

This Windows x64 mod draws a 5 m reverse prediction for truck tractors and trailers. Road grade follows grounded tyre centres and suspension travel, so unequal front/rear suspension height alone does not tilt the guide on level ground. Unknown game executables retain telemetry-only mode.

This is an ATS-only project. “Reverse Posture Assistant For ETS2 1.61.x” is a separate Euro Truck Simulator 2 mod and Workshop item.

## 中文说明

这是 [yyysheng](https://github.com/yyysheng) 维护的 American Truck Simulator 模组仓库。

**Reverse Posture Assistant For ATS 1.61.x v0.11.3** 是美卡专用 Windows x64 倒车轨迹预测模组，仅支持卡车车头与挂车。倒挡时在游戏世界中显示固定 5 米预测边界；坡度按接地轮胎中心和悬挂行程拟合，避免单独调整前后悬挂高度造成平地轨迹倾斜。

ATS 1.61.x 支持 1.61.1.1、1.61.2.0、1.61.3.1；当前本机 Steam 可执行文件内部版本为 1.61.3.18。ATS 1.60.1.8 有精确配置，其他 1.60.x 构建须匹配已启用 Hook 签名。未知可执行文件仅运行遥测模式。

- [源码与完整说明](mods/ATS_Reverse_Trajectory_Predictor)
- [Steam 创意工坊条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3792042919)
- [最新版下载 v0.11.3](https://github.com/yyysheng/ATSmods/releases/tag/reverse-trajectory-predictor-v0.11.3)

本模组与欧卡 2 的 “Reverse Posture Assistant” 属于不同游戏、不同工坊条目的独立项目。
