# ATS Mods

American Truck Simulator mods maintained by [yyysheng](https://github.com/yyysheng).

## Reverse Posture Assistant For ATS 1.61.x

An **American Truck Simulator only** reverse trajectory predictor for Windows x64. It draws the predicted tractor and trailer sweep path in the game world while reversing.

| ATS game branch | Verified executable support | Release |
| --- | --- | --- |
| 1.60.x | 1.60.1.8, plus builds matching the verified hook signatures | [v0.11.2](https://github.com/yyysheng/ATSmods/releases/tag/reverse-trajectory-predictor-v0.11.2) |
| 1.61.x | 1.61.1.1, 1.61.2.0 and locally checked 1.61.3.1 | [v0.11.2](https://github.com/yyysheng/ATSmods/releases/tag/reverse-trajectory-predictor-v0.11.2) |

Unknown executables keep telemetry available but do not enable native hooks. The user completed v0.11.2 in-game validation and reported no abnormalities.

- [Project source and documentation](mods/ATS_Reverse_Trajectory_Predictor)
- [Steam Workshop item](https://steamcommunity.com/sharedfiles/filedetails/?id=3792042919)
- [Latest release downloads](https://github.com/yyysheng/ATSmods/releases/tag/reverse-trajectory-predictor-v0.11.2)

This ATS project is separate from the ETS2 mod titled “Reverse Posture Assistant For ETS2 1.61.x.”

## Repository layout

Each mod is isolated under `mods/` with its own source, documentation, Workshop metadata, packaging tools, and version history.
