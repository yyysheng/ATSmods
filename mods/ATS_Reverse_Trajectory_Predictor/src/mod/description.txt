Reverse Posture Assistant For ATS 1.61.x v0.11.3

仅适用于 American Truck Simulator。倒挡时在游戏世界中显示蓝色车头边界与橙色挂车边界，预测固定 5 米的倒车扫掠路径。轨迹随方向盘、挂车角度、车轮接地、提升状态与可转向轴变化。

v0.11.3 按接地轮胎中心与悬挂行程拟合路面坡度，不再仅跟随车身俯仰/侧倾。平地上单独调整前轮或后轮悬挂高度不会造成虚假的轨迹倾斜；单轴挂车无法确定的方向使用车头轮胎坡度。

此美卡模组与欧卡 2 的 Reverse Posture Assistant 是不同游戏、不同工坊条目的独立项目。仅支持卡车车头与挂车；乘用车模式不显示倒车线。

不需要驾驶室挂件。请另行安装配套运行时 DLL，再启用本模组并重启游戏。工坊订阅不包含 DLL；工坊用户需运行 Install-Workshop.bat。本地完整包用户运行 Install-Full.bat。不要同时启用本地版和工坊版。

兼容：ATS 1.60 / 1.61，Windows x64。精确配置覆盖 ATS 1.60.1.8、1.61.1.1、1.61.2.0、1.61.3.1，以及当前本机 Steam 可执行文件内部版本 1.61.3.18。不匹配时跳过原生 Hook，保留仅遥测模式。

不抓取摄像头、后视镜画面或深度缓冲，不附带 ReShade、dxgi.dll 或 d3d11.dll。
下载：https://github.com/yyysheng/ATSmods/releases/tag/reverse-trajectory-predictor-v0.11.3

American Truck Simulator only. Blue tractor and orange trailer boundaries predict a fixed 5 m path in world space while reversing. Road grade follows grounded tyre centres and per-wheel suspension travel, not chassis pitch/roll alone. No cabin accessory is needed.
Install the runtime DLL, enable this mod and restart ATS. Workshop subscribers must also install the GitHub Workshop runtime package. Do not enable standalone and Workshop copies together.
ATS 1.60 / 1.61, Windows x64; exact profiles cover ATS 1.60.1.8, 1.61.1.1, 1.61.2.0, 1.61.3.1 and local executable file version 1.61.3.18. Other builds retain telemetry-only mode unless their required signatures match.
Truck and trailer support only; no reverse lines in personal vehicle mode. No camera, mirror-image or depth-buffer capture; no bundled ReShade, dxgi.dll or d3d11.dll.
