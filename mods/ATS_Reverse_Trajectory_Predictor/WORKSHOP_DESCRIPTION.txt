[h1]ATS Reverse Trajectory Predictor / 美卡倒车轨迹预测[/h1]
[b]The runtime DLL is required; no cabin accessory is needed. / 需要安装运行时 DLL，无需安装驾驶室挂件。[/b]

[h1]English[/h1]
Reverse Trajectory Predictor adds world-space reverse guidance: two blue tractor boundaries and two orange trailer boundaries over a fixed 5 m prediction path. The curves follow steering and articulation, using wheel contact, lift state and steerable axle angles.

[b]Features[/b]
[list]
[*]Separate tractor and trailer swept-area boundaries.
[*]Prediction lines appear only in reverse gear and hide while paused.
[*]Collisionless world-space models, visible through normal game rendering.
[*]Preserves the game's original trailer guide markers.
[*]No Reverse Assist Anchor or other cabin accessory installation is required.
[*]No camera, mirror-image or depth-buffer capture; no bundled dxgi.dll or d3d11.dll.
[/list]

[b]Installation / upgrade[/b]
1. Subscribe to this item, fully exit ATS and let Steam download the latest resources.
2. Download the v0.10.9 Workshop runtime package, extract it and run Install-Workshop.bat.
[url=https://github.com/yyysheng/ATSmods/releases/download/reverse-trajectory-predictor-v0.10.9/ATS_Reverse_Trajectory_Predictor_v0.10.9_Workshop.zip]Download Workshop runtime v0.10.9[/url]
3. Enable this item in the Mod Manager and disable older standalone copies. Restart the game.
4. Enter a driving session and select reverse gear. No accessory purchase or installation is needed.

[b]A Workshop subscription alone cannot install the required DLL. Update both resources and runtime when upgrading.[/b]
The installer copies the DLL to bin\win_x64 and also to its plugins subfolder if that folder already exists. Success is shown in green; failure is shown in red.

For standalone installation, download the Full package and run Install-Full.bat instead; do not enable standalone and Workshop copies together.
[url=https://github.com/yyysheng/ATSmods/releases/tag/reverse-trajectory-predictor-v0.10.9]Full package and downloads[/url]
If Steam hides the links, search GitHub for yyysheng/ATSmods and open Releases.

[b]Compatibility[/b]
ATS 1.60, Windows x64, with a verified native hook layout. ATS 1.60.1.8 was checked locally. Incompatible builds skip native hooks and retain telemetry-only mode. This release does not claim support for 1.61 or older branches such as 1.59. Automated checks passed; in-game visual acceptance of v0.10.9 has not been performed.

[h1]中文[/h1]
美卡倒车轨迹预测直接在游戏世界中显示两条蓝色车头边界与两条橙色挂车边界，固定预测沿倒车路径未来 5 米的扫掠范围。轨迹随方向盘、车头与挂车夹角变化，并考虑实际车轮接地、提升状态和可转向轴。

[b]主要功能[/b]
[list]
[*]车头与挂车扫掠边界分色显示。
[*]仅在倒挡时显示，非倒挡与暂停时隐藏。
[*]使用无碰撞世界模型，可通过游戏正常视角观察。
[*]保留游戏原生挂车提示标记。
[*]不需要安装 Reverse Assist Anchor 或其他驾驶室挂件。
[*]不抓取摄像头、后视镜画面或深度缓冲，不附带 dxgi.dll 或 d3d11.dll。
[/list]
