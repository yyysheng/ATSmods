[h1]English[/h1]
Reverse Trajectory Predictor adds world-space reverse guidance: two blue tractor boundaries and two orange trailer boundaries over a fixed 5 m prediction path. The curves follow steering and articulation, using wheel contact, lift state and steerable axle angles. Prediction lines appear only in reverse gear and hide while paused.

[b]What changed in v0.11.0[/b]
[list]
[*]Adds ATS 1.61.x with an exact profile checked against the 1.61.1.1 Steam public executable; validates its four entry hooks and four entity helpers.
[*]Keeps the exact ATS 1.60.1.8 profile and a signature-compatible fallback for other matching ATS 1.60 builds.
[*]Preserves the original game trailer marker and telemetry-only fallback for unknown or mismatched executable builds.
[/list]

[b]Installation / upgrade[/b]
1. Exit ATS and let Steam download this item's latest content.
2. Download v0.11.0 Runtime for Workshop, extract it and run Install-Workshop.bat.
[url=https://github.com/yyysheng/ATSmods/releases/download/reverse-trajectory-predictor-v0.11.0/ATS_Reverse_Trajectory_Predictor_v0.11.0_Workshop.zip]Download Runtime for Workshop v0.11.0[/url]
3. Enable this Workshop item in the Mod Manager. Disable older local copies of Reverse Trajectory Predictor, then restart the game.

[b]A Workshop subscription alone cannot install the required DLL. Update the runtime DLL and Workshop content together.[/b]
For standalone installation, use the Full package instead of subscribing; do not enable both copies:
[url=https://github.com/yyysheng/ATSmods/releases/tag/reverse-trajectory-predictor-v0.11.0]v0.11.0 downloads and release notes[/url]
If Steam hides the link, search GitHub for yyysheng/ATSmods and open Releases.

Compatibility: ATS 1.61.* and 1.60.*, Windows x64. Exact profiles are checked against ATS 1.61.1.1 and 1.60.1.8; compatible ATS 1.60 builds require matching hook signatures. Unverified builds use telemetry-only mode. In-game visual acceptance of v0.11.0 has not been performed. No camera, mirror or depth-buffer capture; no bundled dxgi.dll or d3d11.dll. No cabin accessory is required.
