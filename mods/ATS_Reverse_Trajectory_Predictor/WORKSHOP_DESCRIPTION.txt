[h1]Reverse Posture Assistant For ATS 1.61.x[/h1]
[b]American Truck Simulator only · v0.11.3 · ATS 1.60.x / 1.61.x · Windows x64[/b]

While reversing, this mod draws the predicted tractor and trailer sweep path directly in the ATS game world. Blue lines mark the tractor boundaries; orange lines mark the trailer boundaries. The fixed prediction distance is 5 m and the path responds to steering, trailer angle, wheel contact, lift state and steerable axles.

[b]Game scope:[/b] This Workshop item is for American Truck Simulator. “Reverse Posture Assistant For ETS2 1.61.x” is a separate mod for Euro Truck Simulator 2.

[b]Features[/b]
[list]
[*]World-space prediction lines appear in reverse gear and hide while paused or outside reverse gear.
[*]Ground grade follows grounded tyre centres and per-wheel suspension travel, not chassis pitch/roll alone. Changing front or rear suspension height by itself will not tilt the guide on level ground.
[*]A single-axle trailer reuses the tractor tyre fit only for the direction its own wheel layout cannot determine.
[*]No cabin accessory is required. The game's trailer guide markers remain unchanged.
[*]No camera, mirror-image or depth-buffer capture; no bundled ReShade, dxgi.dll or d3d11.dll.
[/list]

[b]v0.11.3 · ground-slope update[/b]
[list]
[*]Fits road slope from grounded wheel centres reconstructed with suspension travel, filtering suspension-induced chassis pitch/roll from the guide.
[*]Retains ATS 1.61.3.1, 1.61.2.0, 1.61.1.1 and 1.60.1.8 exact Windows x64 profiles, plus the ATS 1.60 signature-compatible fallback.
[*]Unknown or modified executables skip native hooks and keep telemetry-only mode.
[*]Truck and trailer support only; personal vehicle mode does not show prediction lines.
[/list]

[b]Workshop installation / update[/b]
1. Subscribe to this ATS Workshop item and let Steam download its resources.
2. Download the [url=https://github.com/yyysheng/ATSmods/releases/download/reverse-trajectory-predictor-v0.11.3/Reverse_Posture_Assistant_For_ATS_v0.11.3_Workshop.zip]v0.11.3 Workshop runtime package[/url]. Exit ATS, extract the ZIP and run Install-Workshop.bat.
3. Enable this Workshop item in the Mod Manager, disable any standalone copy, then restart ATS.

[b]A Workshop subscription does not install the runtime DLL.[/b] Steam supplies the mod resources; the GitHub package installs the DLL. For standalone use, download the [url=https://github.com/yyysheng/ATSmods/releases/download/reverse-trajectory-predictor-v0.11.3/Reverse_Posture_Assistant_For_ATS_v0.11.3_Full.zip]Full package[/url] instead. Do not enable the Full and Workshop copies together.

[b]Compatibility:[/b] ATS 1.61.3.1 has exact Windows x64 profiles, including the current local Steam executable file version 1.61.3.18; ATS 1.61.2.0 and 1.61.1.1 also have exact profiles. ATS 1.60.1.8 has an exact profile; other ATS 1.60 builds require matching enabled-hook signatures. Unknown builds remain in telemetry-only mode.

[h1]简体中文[/h1]
倒车时，本模组直接在美卡游戏世界中绘制车头与挂车的预测扫掠路径：蓝线表示车头边界，橙线表示挂车边界，固定预测距离为 5 米。轨迹随方向盘、挂车角度、车轮接地、提升状态及可转向轴变化。

[b]游戏范围：[/b]本条目仅适用于 American Truck Simulator。“Reverse Posture Assistant For ETS2 1.61.x”是欧卡 2 的另一个独立模组。

[b]功能特点[/b]
[list]
[*]只在倒挡时显示预测线；暂停或离开倒挡时隐藏。
[*]坡度按接地轮胎中心与悬挂行程拟合，不再仅跟随车身俯仰/侧倾；平地上单独调整前后悬挂高度不会造成轨迹倾斜。
[*]单轴挂车自身无法拟合的方向，会回退使用车头的轮胎坡度。
[*]不需要驾驶室挂件，保留游戏原生挂车提示标记。
[*]不抓取摄像头、后视镜画面或深度缓冲，不附带 ReShade、dxgi.dll 或 d3d11.dll。
[/list]

[b]v0.11.3 · 坡度拟合更新[/b]
[list]
[*]根据接地轮胎中心和悬挂行程拟合路面坡度，避免悬挂导致的车身俯仰/侧倾影响轨迹线。
[*]保留 ATS 1.61.3.1（含当前本机 Steam 可执行文件内部版本 1.61.3.18）、1.61.2.0、1.61.1.1、1.60.1.8 精确配置，以及 ATS 1.60 签名兼容回退。
[*]未知或修改过的可执行文件会跳过原生 Hook，仅保留遥测模式。
[*]仅支持卡车车头与挂车；乘用车模式不显示倒车线。
[/list]
