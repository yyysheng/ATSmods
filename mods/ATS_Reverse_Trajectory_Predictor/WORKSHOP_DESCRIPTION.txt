[h1]Reverse Posture Assistant For ATS 1.61.x[/h1]
[b]American Truck Simulator only · v0.11.1 · ATS 1.60.x / 1.61.x · Windows x64[/b]

While reversing, this mod draws the predicted tractor and trailer sweep path directly in the ATS game world. Blue lines mark the tractor boundaries; orange lines mark the trailer boundaries. The fixed prediction distance is 5 m and the path responds to steering, trailer angle, wheel contact, lift state and steerable axles.

[b]Game scope:[/b] This Workshop item is for American Truck Simulator and is named “Reverse Posture Assistant For ATS 1.61.x.” “Reverse Posture Assistant For ETS2 1.61.x” is a separate mod for Euro Truck Simulator 2.

[b]Features[/b]
[list]
[*]World-space prediction lines appear in reverse gear and hide while paused or outside reverse gear.
[*]No cabin accessory is required. The game's trailer guide markers remain unchanged.
[*]No camera, mirror-image or depth-buffer capture; no bundled ReShade, dxgi.dll or d3d11.dll.
[/list]

[b]v0.11.1 · ATS 1.61.2.0 update[/b]
[list]
[*]Adds an exact profile for the installed ATS 1.61.2.0 Steam executable. Four entry hooks and four required entity helpers are checked before native hooks are enabled.
[*]Retains the exact ATS 1.61.1.1 and 1.60.1.8 profiles, plus the ATS 1.60 signature-compatible fallback.
[*]Unknown or modified executables skip native hooks and keep telemetry-only mode.
[/list]

[b]Workshop installation / update[/b]
1. Subscribe to this ATS Workshop item and let Steam download its resources.
2. Download the [url=https://github.com/yyysheng/ATSmods/releases/download/reverse-trajectory-predictor-v0.11.1/Reverse_Posture_Assistant_For_ATS_v0.11.1_Workshop.zip]v0.11.1 Workshop runtime package[/url]. Exit ATS, extract the ZIP and run Install-Workshop.bat.
3. Enable this Workshop item in the Mod Manager, disable any standalone copy, then restart ATS.

[b]A Workshop subscription does not install the runtime DLL.[/b] Steam supplies the mod resources; the GitHub package installs the DLL. For standalone use, download the [url=https://github.com/yyysheng/ATSmods/releases/download/reverse-trajectory-predictor-v0.11.1/Reverse_Posture_Assistant_For_ATS_v0.11.1_Full.zip]Full package[/url] instead. Do not enable the Full and Workshop copies together.

[b]Compatibility:[/b] ATS 1.61.2.0 and 1.61.1.1 have exact Windows x64 profiles. ATS 1.60.1.8 has an exact profile; other ATS 1.60 builds require matching enabled-hook signatures. Unknown builds remain in telemetry-only mode. Automated build/profile and kinematics checks are recorded in the release documentation; in-game visual acceptance of v0.11.1 has not been performed.

[h1]简体中文[/h1]
倒车时，本模组直接在美卡游戏世界中绘制车头与挂车的预测扫掠路径：蓝线表示车头边界，橙线表示挂车边界，固定预测距离为 5 米。轨迹随方向盘、挂车角度、车轮接地、提升状态及可转向轴变化。

[b]游戏范围：[/b]本条目仅适用于 American Truck Simulator，名称为“Reverse Posture Assistant For ATS 1.61.x”。“Reverse Posture Assistant For ETS2 1.61.x”是欧卡 2 的另一个独立模组，与本美卡条目不同。

[b]功能特点[/b]
[list]
[*]只在倒挡时显示预测线；暂停或离开倒挡时隐藏。
[*]不需要驾驶室挂件，保留游戏原生挂车提示标记。
[*]不抓取摄像头、后视镜画面或深度缓冲，不附带 ReShade、dxgi.dll 或 d3d11.dll。
[/list]

[b]v0.11.1 · ATS 1.61.2.0 适配[/b]
[list]
[*]新增 ATS 1.61.2.0 Steam 可执行文件精确配置。启用原生 Hook 前检查 4 个入口 Hook 和 4 个必需实体辅助函数。
[*]保留 ATS 1.61.1.1、1.60.1.8 精确配置，以及 ATS 1.60 签名兼容回退。
[*]未知或修改过的可执行文件会跳过原生 Hook，仅保留遥测模式。
[/list]
