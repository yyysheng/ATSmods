# ATS Reverse Trajectory Predictor v0.10.8

Reverse posture and trajectory assistance for American Truck Simulator 1.60.1.8 on Windows x64.

## Downloads

- `ATS_Reverse_Trajectory_Predictor_v0.10.8_Full.zip`: installs the runtime DLL and the local `.scs` mod.
- `ATS_Reverse_Trajectory_Predictor_v0.10.8_Workshop.zip`: installs the runtime DLL for Steam Workshop subscribers.

## Installation

Exit ATS, extract the selected package, and run its `.bat` installer. Successful installation is shown in green; failures are shown in red. The DLL is installed in `bin\win_x64` and is also copied into `bin\win_x64\plugins` when that folder exists.

Full-package users must enable **美卡倒车轨迹预测** in the ATS Mod Manager. Workshop users must subscribe to the Workshop item and install the Workshop runtime package from this release. In either case, install `Reverse Assist Anchor` in a cabin accessory slot before driving.

## Compatibility

- American Truck Simulator `1.60.1.8`
- Windows x64
